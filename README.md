# Angelica game map

The game map tells [Angelica](https://github.com/AngelicaProject/angelica) where functions, data, and structure fields are in each build of FINAL FANTASY XIV. Plugins refer to entries of this map by name, so after a game patch only this map is updated; plugins are not rebuilt.

## Layout

- `map.toml`: format version.
- `entries/`: hand-maintained entries, one file per area.
- `sheets/`: sheet schemas, names for the columns of the game's Excel sheets, one file per sheet.
- `state/`: state tables, the game state plugins may read, one file per domain.
- `builds/`: build records generated by `angelica map verify`, one per game executable.

The format is specified in the `angelica` repository: [game map format v1](https://github.com/AngelicaProject/angelica/blob/main/docs/formats/game-map-v1.md).
